按「置頂小視窗」，小 Claude 會變成浮在最上層的小視窗，可以拖到螢幕角落、拉大拉小。

這台電腦不能直接置頂？用 Windows 小工具

  1. 到 Microsoft Store 搜尋並安裝「PowerToys」（微軟官方、免費）。
  2. 在 Chrome 把這個網址拖出成獨立視窗，縮小到適合大小。
  3. 點一下那個視窗，按 Win + Ctrl + T，它就會固定在最上層（再按一次取消）。

小 Claude 的表情

  1. 😴 休息中：沒有工作在跑。
  2. 💻 工作中：Claude 正在幫您做事。
  3. 🎉 做完了：外框閃綠光，回 Claude App 看結果。
  4. ✋ 有問題問您：外框閃黃光，泡泡會寫問題摘要。

點小 Claude 或按「我知道了」就會停止閃爍。上課模式只閃光不出聲；關掉後會發出輕柔提示音。
